## About

Class exercises covering advanced Python topics, kept as both a plain script and a notebook so they can be read in an editor or run interactively in Google Colab.

## Contents

| File | Description |
|---|---|
| `ALGORITMOSAVANÇADOS.py` | Advanced algorithms exercises (script / Colab format) |
| `ALGORITMOSAVANÇADOS_py.ipynb` | The same exercises as a Jupyter notebook |

### Topics

- **Vectors, matrices and lists** — creation, indexing and manipulation
- **Advanced algorithms** — sorting, searching and iterative problem solving
- **Data structures** — working with nested and multidimensional collections

## How to run

**As a notebook** — open `ALGORITMOSAVANÇADOS_py.ipynb` on GitHub or in Colab:

```bash
git clone https://github.com/vitoriaayres/PYTHON.EXERCICIOS.git
cd PYTHON.EXERCICIOS
pip install nbconvert
jupyter notebook ALGORITMOSAVANÇADOS_py.ipynb
```

**As a script:**

```bash
python ALGORITMOSAVANÇADOS.py
```

> 💡 The `.py` file is stored in notebook (nbformat/Colab) format, so it opens correctly in Colab even though the extension is `.py`.
